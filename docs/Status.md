  `tester` include no signing until the paid membership (D20 Q9b, Q10).

  `app/ios/Flutter/words.g.xcconfig`; all three flavours carry the microphone text, EM·3, in English and Swedish

- The journal's store (D49 b, c), with no screen yet: `app/lib/journal/`. One JSON file per night, format version 1,
  in `Library/Application Support/Journal`; the folder excluded from backup; the folder and every file with complete
  file protection, through the Swift channel in `AppDelegate.swift`. A save writes a temporary file, flushes it to the
  disk (F_FULLFSYNC, else fsync) and renames it; a failed save removes its own temporary file. Every store operation
  waits for the one before it (one queue). Deleting a night removes its file and any temporary file of its save; a
  file that does not read as a night is skipped (`journalFileSkipped`) and never touched; Delete journal is a native
  delete-all that removes every entry whatever its name and does not stop at one it cannot remove, the first-use flag
  included (D54). The format may change freely until it first reaches the founder app (D49 O5).

  colour (`color.page`), no logo, no words; `resumed` removes it (`app/lib/core/privacy_cover.dart`, in
  `app.dart`'s builder, so in all three apps).
- Third-party keyboards are refused in all three apps (D50 1): `AppDelegate.swift` answers `false` for the keyboard
  extension point, `true` for every other.
- SoulDreams Dev runs the phone check when built with `--dart-define=JOURNAL_SELF_CHECK=true`, and shows one empty
